# AWS Certified Machine Learning Engineer Associate Lab Guide

This folder contains twelve practical labs for TGS-2024049340 - AWS Certified Machine Learning Engineer Associate Training. The course runs over **3 days with exactly four labs per day**, mapped to the four MLA-C01 exam domains.

## Lab Sequence

### Day 1 — Data Preparation for Machine Learning (Domain 1)

| Lab | File | Outcome |
| --- | --- | --- |
| 1 | [Account Safety and IAM Baseline](lab-01-account-safety-iam-baseline.md) | Secured ML workspace: identity, least-privilege IAM, execution role, MFA, budget and KMS. |
| 2 | [S3 ML Data Lake and Data Formats](lab-02-s3-ml-data-lake-data-formats.md) | Encrypted S3 data lake with six prefixes, lifecycle rules and a data-format comparison. |
| 3 | [Batch and Streaming Ingestion with Glue, Athena and Kinesis](lab-03-batch-streaming-ingestion-glue-athena-kinesis.md) | Cataloged, Athena-queryable batch data plus a Kinesis streaming design. |
| 4 | [Feature Engineering, Feature Store, Labelling and Data Quality](lab-04-feature-engineering-feature-store-labelling-data-quality.md) | Feature flow, Feature Store design and feature/quality/bias checklists. |

### Day 2 — ML Model Development (Domain 2)

| Lab | File | Outcome |
| --- | --- | --- |
| 5 | [Modelling Approach, Algorithms and Managed AI Services](lab-05-modelling-approach-algorithms-managed-ai-services.md) | Model/service selection matrix for ML and AI business scenarios. |
| 6 | [SageMaker Training Jobs and Debugger](lab-06-sagemaker-training-jobs-debugger.md) | Running training job with Debugger/Profiler findings and a config checklist. |
| 7 | [Automatic Model Tuning, Experiments and Model Registry](lab-07-automatic-model-tuning-experiments-model-registry.md) | Tuning plan, experiment-tracking scheme and model-versioning workflow. |
| 8 | [Model Evaluation, Metrics, Bias and Explainability](lab-08-model-evaluation-metrics-bias-explainability.md) | Evaluation plan and acceptance checklist with bias/explainability checks. |

### Day 3 — Deployment, Monitoring, Security & Exam Review (Domains 3 & 4)

| Lab | File | Outcome |
| --- | --- | --- |
| 9 | [Deployment Options, Endpoints, Batch Transform and Auto Scaling](lab-09-deployment-endpoints-batch-transform-auto-scaling.md) | Inference-option comparison and an auto-scaling/rollback checklist. |
| 10 | [MLOps Pipelines, CI/CD, Orchestration and IaC](lab-10-mlops-pipelines-cicd-orchestration-iac.md) | End-to-end MLOps pipeline design with approval, CI/CD and IaC touchpoints. |
| 11 | [Model Monitoring, Drift and Observability](lab-11-model-monitoring-drift-observability.md) | Monitoring design with data capture, drift schedules, alarms and retrain loop. |
| 12 | [Security, Governance, Cost Optimisation and Exam Review](lab-12-security-governance-cost-optimisation-exam-review.md) | Security/governance/cost checklists, lab-to-domain map and timed review plan. |
