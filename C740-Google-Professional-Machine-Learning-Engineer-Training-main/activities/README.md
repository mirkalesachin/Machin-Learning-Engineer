# Google Professional Machine Learning Engineer Training — Activities

**C740 · v2.0 · 12 September 2026**

Each activity is self-contained with a detailed printable guide, mock data or configuration, scripts, acceptance checks and cleanup guidance.

- [Activity 01 — Create a Safe Google Cloud Training Environment](activity-01-safe-google-cloud-environment/README.md) — Create a Google account, Cloud project, billing budget, IAM boundary and Cloud Shell workspace.
- [Activity 02 — Draft an ML Architecture Decision Record](activity-02-ml-architecture-decision/README.md) — Convert business volume, latency, security and explainability needs into a service decision.
- [Activity 03 — Train and Evaluate a BigQuery ML Churn Model](activity-03-bigquery-ml-churn/README.md) — Run SQL-defined logistic regression, evaluation and batch prediction on mock customer data.
- [Activity 04 — Design an AutoML Tabular Experiment](activity-04-automl-tabular-plan/README.md) — Create a dataset specification, split plan, budget and evaluation slice gate.
- [Activity 05 — Compare Pretrained Google Cloud AI APIs](activity-05-pretrained-ai-apis/README.md) — Prepare Vision, Document AI and Natural Language requests and interpret mock responses.
- [Activity 06 — Build a Data Quality and Feature Pipeline](activity-06-data-quality-feature-pipeline/README.md) — Validate schema, repair missing values, encode features and preserve a training manifest.
- [Activity 07 — Train a TensorFlow/Keras Model](activity-07-tensorflow-keras-training/README.md) — Use tf.data, a Keras network, early stopping and SavedModel verification.
- [Activity 08 — Package a Vertex AI Custom Training Job](activity-08-vertex-custom-training/README.md) — Build a reproducible training package and container with managed output paths.
- [Activity 09 — Analyze Vertex AI Hyperparameter Trials](activity-09-hyperparameter-tuning/README.md) — Define a Vizier-style search space and select a trial using quality and cost evidence.
- [Activity 10 — Plan Distributed PyTorch GPU Training](activity-10-distributed-gpu-training/README.md) — Configure torchrun-style workers, checkpoints and scaling-efficiency diagnostics.
- [Activity 11 — Verify Feature Store Point-in-Time Parity](activity-11-feature-store-parity/README.md) — Model offline/online feature definitions and detect stale or leaked features.
- [Activity 12 — Register and Canary a Model Version](activity-12-model-registry-canary/README.md) — Create registry metadata, traffic split, guardrails and rollback evidence.
- [Activity 13 — Serve a Model on Cloud Run](activity-13-cloud-run-serving/README.md) — Package a Flask prediction API, test its contract and analyze load-test results.
- [Activity 14 — Compile a Vertex AI Pipeline](activity-14-vertex-pipeline/README.md) — Connect validate, transform, train, evaluate and conditional deployment components.
- [Activity 15 — Design an ML CI/CD/CT Release](activity-15-ml-cicd-ct/README.md) — Create Cloud Build gates, artifact provenance and a model card release record.
- [Activity 16 — Investigate Drift, Bias and an ML Incident](activity-16-model-monitoring-incident/README.md) — Calculate drift and slice metrics, enforce SLOs and produce an incident evidence pack.
