## About the course

This practical course develops the architecture, data, training, deployment, orchestration and monitoring judgment needed to build production machine-learning solutions on Google Cloud. It follows the six current certification domains.

## Learning outcomes

By the end of the course, learners can:

- assess and draft Google Cloud solution specifications for business machine-learning requirements;
- develop implementation plans and resolve issues for Google Cloud machine-learning solutions; and
- develop and review metrics processes for Google Cloud machine-learning implementations.

## Topics covered

- low-code AI architecture with BigQuery ML, AutoML, pretrained APIs and foundation models;
- data modalities, preprocessing, feature engineering, privacy, secure workbenches and lineage;
- TensorFlow/Keras, Vertex AI custom training, hyperparameter tuning and distributed accelerators;
- model registry, canary rollout, Cloud Run/GKE and managed online or batch serving;
- Vertex AI Pipelines, Kubeflow, Composer, Ray and CI/CD/CT; and
- responsible AI, Model Armor, drift, skew, bias, SLOs, incident response and cost optimisation.

## Requirements and cost safety

Most Activities run locally with Python 3.11+ and supplied mock data. Live Google Cloud execution is optional unless directed by the trainer. Use an isolated training project, budget alerts, least privilege, approved regions and the cleanup steps in each guide.
